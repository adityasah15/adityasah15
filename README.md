## Currently Building

### 🚀 SkillShift

**SkillShift** is a production-oriented freelance marketplace being built from scratch with **NestJS and TypeScript**.

The core workflow is:

`Service Discovery → Order → Escrow → Delivery → Completion / Dispute → Review`

The project is designed around three roles:

* **Client** — discovers services, places orders, pays, accepts delivery or raises disputes
* **Freelancer** — publishes services, delivers work and receives earnings
* **Admin** — moderates listings, resolves disputes and manages platform analytics

### Planned system

* Authentication and email verification
* JWT access tokens and refresh-token rotation
* Role-based authorization
* Service listings and moderation
* Search and filtering
* Order lifecycle and state management
* Simulated wallet and escrow system
* Transaction history and audit logs
* Real-time order-based chat
* Dispute management
* File uploads using object storage
* Email notifications and background jobs
* Admin panel and analytics
* Minimal Next.js frontend

The architecture is intentionally a **modular NestJS monolith** rather than prematurely splitting the application into microservices.

> **Note:** SkillShift is actively under development. The feature list above describes the project's blueprint and direction; it does not imply that every listed feature is currently implemented.

**Current stack:** TypeScript · NestJS · PostgreSQL · Prisma · Redis · Docker · JWT · Passport · Jest · Supertest
